# SruPulse

SruPulse помогает собрать компанию на ближайшее время. Автор пишет до 280 символов, выбирает срок 30, 60 или 120 минут и конкретных получателей. Автор видит свой статус всегда; публикация без других получателей запрещена.

Получатель может откликнуться, отменить свой отклик и открыть личный чат с автором. Автор видит откликнувшихся и может написать выбранному человеку. Завершение статуса требует подтверждения. Истёкший или закрытый статус не принимает новые отклики, включая запросы из старого экрана.

Статусы обновляются каждые 30 секунд и при возвращении на экран; список откликов, пока он открыт, каждые 10 секунд. Кнопка обновления позволяет запросить данные сразу. Ошибки не очищают текст публикации и выбранную аудиторию.

## Личная встреча в SruDay

Кнопка «В календарь» открывает отдельное подтверждение названия, начала и окончания встречи. Время вводится в часовом поясе устройства, его название показано рядом. В SruDay отправляются только эти поля и признак обычного события. Список получателей и откликов не передаётся. Форма сохраняется на экране, даже если исходный статус успел истечь.

Нужен подключённый аккаунт SruDay. Создание использует его публичный API через SruNal. Автоматических повторов нет: если подтверждение сохранения не пришло, сначала нужно проверить календарь. Внешний SruDay пока не гарантирует идемпотентность создания события.

## Доступ и API

- Текст статуса хранится зашифрованным существующим механизмом защиты содержимого SruNal.
- Блокировка в любую сторону исключает просмотр и отклик. Доступ через сообщество требует его активности и действующего участия.
- Получатели должны существовать, иметь активный аккаунт и быть доступны автору. Сервер принимает до 100 выбранных людей и срок от минуты до 24 часов.
- Имена откликнувшихся доступны только автору, с повторной проверкой блокировок. Для больших сообществ пока возвращаются первые 100 откликов.
- GET /api/v1/pulse/{id}/responses возвращает автору {people: [{id, public_name}]}.
- POST /api/v1/pulse/{id}/responses идемпотентно добавляет собственный отклик; DELETE по тому же адресу отменяет только собственный отклик.
- Создание личной встречи: POST /api/v1/day/events с {title, starts_at, ends_at, all_day: false}, после явного подтверждения.

Проверки: PostgreSQL-тесты аудитории, обеих блокировок, шифрования, срока, закрытия, повторных откликов, отмены и прав на список людей; проверки времени и интервала встречи; сборка TypeScript. Браузерный сценарий проверяет реальный API Pulse и согласованный mock-ответ Day, сохранение черновиков при ошибках, подтверждение полей встречи и мобильную тёмную тему. Реальный внешний SruDay и Telegram на телефонах проверяются отдельно.

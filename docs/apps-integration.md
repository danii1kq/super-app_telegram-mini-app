# Tinder, Farm и Aura в актуальном SruNal

Интеграция 14 ноября 2026 года. База: `main` на `8f4f278`; источник приложений: `feature/farm-game` на `49a2c28`. Истории Git не имеют общего предка, поэтому перенесены папки приложений, ресурсы и необходимые подключения. Старые версии остальных модулей из игровой ветки не использованы.

## Навигация и поведение

- SruTinder: `/apps/tinder`. Анкеты, фото, предпочтения, лайки и совпадения. Взаимное совпадение открывает контакт через `https://t.me/<username>`. Если публичного username нет, доступен профиль человека в SruNal. Telegram ID не раскрывается. Внутренние чаты не восстанавливаются.
- SruGame: `/apps/game`, общий вход в игры из каталога.
- SruFarm: `/apps/game/farm`. Сохранены экономика, растения, уровни, мутации, экспедиции, заказы, темы и игры исходной ветки. `/apps/farm` перенаправляется на новый путь.
- SruAura: `/apps/game/aura`. Сохранены герои, математические задания, бои, реликвии, иллюстрации, улучшения и рейтинги. `/apps/aura` также перенаправляется на новый путь.

Оболочка использует переводы RU/KK/EN. Основные игровые экраны сохраняют исходный русский интерфейс. Все существовавшие переводы main оставлены без изменений.

## Совместимость с main

SruSplit, SruDay, SruPulse, Docgen, SruNotes, лента, профили, авторизация, общие стили и нижняя навигация сохранены из main. Сохраняются карточки публикаций с просмотрами, календарь с импортом и погодой, совместные чеки и подтверждения возвратов. Каталог не возвращает отдельную карточку SruDay, название Docgen не меняется.

В общих файлах добавлены только подключения новых приложений, маршруты, пункты каталога, недостающие переводы, загрузка приватных изображений, поддержка платежных методов Farm и обработка уведомлений Tinder. Новые зависимости не устанавливались.

Для Tinder исправлена привязка к удалённым чатам, загрузка фото выполняется после создания анкеты, временные URL фото освобождаются. Взаимные лайки сериализуются по паре пользователей, повторный запрос не создаёт второе совпадение или повторные уведомления. Блокировки учитываются при лайках, чтении совпадений и доступе к фото. Незаданный возраст сохраняется как NULL, указанный допускается от 18 до 120.

## Миграции и запуск

Все миграции main `000001-000020` сохранены. Игровые миграции добавлены после них:

| Номер | Изменение |
| --- | --- |
| `000021-000025` | Farm, темы, миры, совместные игровые раунды и комиссия |
| `000026-000030` | Tinder, университет, фото, предпочтения, уведомления |
| `000031-000032` | Aura и подземелья |

Перед запуском новых API применить миграции к основной БД обычным `migrate`, затем перезапустить API и worker и обновить frontend. Существующие данные основных приложений не удаляются и не переносятся в другой формат.

Нумерация в отдельной БД старой игровой ветки отличается. Этот порядок рассчитан на обновление БД main; слияние содержимого двух самостоятельных БД и перенос игрового прогресса между ними не выполнялись.

Платежи за косметические темы Farm по умолчанию выключены. Для включения нужны `SRUNAL_FARM_STARS_ENABLED=true`, существующие настройки бота и webhook с секретом. Игровые монеты отдельны от Telegram Stars. Никакие реальные платежи при интеграции не выполнялись.

Tinder использует существующий worker с арендой заданий и отдельным ключом доставки. Для его сообщений используется собственный контекст шифрования и собственные настройки лайков/совпадений; отключение уведомлений SruSplit не отключает Tinder. Пользователь явно разрешает сообщения кнопкой в Tinder через Telegram `requestWriteAccess`. Для кнопок бота нужен `SRUNAL_BOT_USERNAME`, дополнительно может использоваться `SRUNAL_MINIAPP_NAME`.

## Проверка

Проверяются все Go-пакеты на отдельной PostgreSQL 18, `go vet`, production-сборка и Node-тесты новых приложений вместе с SruSplit. Дополнительно проверяются первоначальная загрузка игровых экранов, ресурсы Aura, сохранение растения после перезагрузки, анкета с фото и оба варианта контакта Tinder.

Отдельное сравнение с `8f4f278` подтверждает сохранность основных модулей, 40 файлов прежних миграций и всех 1356 существовавших переводов. Реальные платежи Stars и доставка сообщений живым пользователям не проверялись; для платежей и доставки используются тестовые отправители.

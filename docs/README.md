# SruNal: соцсеть и super app

Статус: реализуемая версия. Актуальные изменения: 13 ноября 2026 года. Ранние проектные документы сохраняют историю решений; при расхождении приоритет у описанных ниже текущих возможностей.

**SruNal является соцсетью с лентой, профилями и календарём внутри Telegram Mini App.** Личные сообщения открываются в Telegram. Внутренние диалоги, группы, пересылка файлов и SSE чатов удалены из клиента и API.

Основные вкладки: лента, календарь SruDay, приложения и собственный профиль. Каталог содержит **Docgen**, **SruPulse**, **SruNotes** и **SruSplit**. SruDay больше не дублируется карточкой приложения.

Техническая основа: **React 19 + Vite + TypeScript**, UI/UX существующего SruNal DocGen, **Go** и **PostgreSQL 18**. API и фоновый worker запускаются отдельно, уведомления приходят **в личный чат Telegram-бота**. Приватные поля планируем шифровать на сервере, случайные токены хранить хэшами.

## Основа концепции

- SruNal отвечает за ленту, профили, календарь и каталог приложений.
- У каждого приложения свой интерфейс, данные и основная задача.
- Код приложения находится рядом: `web/src/apps/<id>` на React и `backend/internal/apps/<id>` на Go. Лента и профили находятся в `core`; модуль Day переиспользуется основной вкладкой календаря.
- Связи включаются для конкретного удобства: поделиться заметкой, добавить подтверждённую встречу из Pulse в календарь или учесть общие расходы.
- Можно пользоваться приложениями без публикаций и переписки. Заказы, заметки, календарь и расходы открываются другим только по выбранным разрешениям.
- Начальная аудитория: пользователи существующих проектов, прежде всего студенты. Каталог можно расширять приложениями для других задач.

## Дополнительные приложения

**SruPulse:** показать друзьям «свободен ещё 40 минут» и быстро собрать компанию.

**SruNotes:** создавать обычные текстовые заметки и делиться выбранными заметками с другими.

**SruSplit:** вести общие расходы компании и рассчитывать, кто сколько потратил и кому сколько вернуть.

Подробные сценарии находятся в [описании приложений](02-apps-and-ideas.md).

Вложения и тексты импортов не публикуются в ленте автоматически. Приватные данные раскрываются только по выбранным разрешениям. Исторические SQL-миграции чатов сохранены для совместимости уже установленных БД, но обработчиков и читающего их кода в приложении нет.
